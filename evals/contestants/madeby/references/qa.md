# Prueba de calidad

El núcleo carga este archivo solo en la pasada final de un cambio sustancial: más de ~10 líneas cambiadas, o tipo de contenido incierto. Para el resto alcanza la pregunta residente del núcleo.

Califica 1–10 en cada dimensión. Menos de 35/50: vuelve a revisar antes de entregar.

| Dimensión | Pregunta |
|-----------|----------|
| Concreción | ¿Hay datos reales o solo valoraciones? |
| Ritmo | ¿Varía la longitud de las oraciones? |
| Confianza | ¿Le habla al lector como a una persona real? |
| Autenticidad | ¿Suena a alguien que conoce el tema? |
| Densidad | ¿Hay algo que sobra? |

Si una dimensión baja de 5, esa se corrige primero; repite la prueba después de corregir. La nota es control interno: no se muestra al usuario salvo que la pida.
